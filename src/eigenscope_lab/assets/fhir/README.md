# HL7 FHIR R4 validation schema

`fhir-r4.schema.json.zip` is the unmodified HL7 FHIR R4 (4.0.1) JSON schema
distribution. Keeping the complete definitions preserves all referenced types.
The healthcare scenario validates its resources offline with `jsonschema` and
also applies its bounded patient, pump, unit, time-window and approval rules.
